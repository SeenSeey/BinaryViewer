# Binary Viewer

Небольшое read-only Qt Widgets приложение для просмотра бинарных файлов порциями,
выделения непрерывного диапазона байтов и отображения его двоичного представления
с учётом размера слова и порядка байт.

## Требования

- CMake 3.16 или новее;
- компилятор с поддержкой C++20;
- Qt 5.15 с компонентами Core, Gui, Widgets и Test (для тестов).

## Сборка и тесты

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

## Запуск

```bash
./build/BinaryViewer
```

## Интерфейс

`Open File` (или `Ctrl+O`) открывает произвольный файл. В toolbar задаются размер
порции от 1 до 4 194 304 байт (по умолчанию 4096 байт), порядок байт и размер
слова 16/32/64/128 bit. Порядок байт и размер слова выбираются сегментированными
переключателями. Кнопки Previous/Next и клавиши `PageUp`/`PageDown` переключают порции. Левая область показывает по 16 байт в строке с абсолютными 64-битными смещениями. Перетаскивание мышью выделяет непрерывный диапазон байтов; правая область сразу показывает результат преобразования.
В память загружается только текущая порция файла.
